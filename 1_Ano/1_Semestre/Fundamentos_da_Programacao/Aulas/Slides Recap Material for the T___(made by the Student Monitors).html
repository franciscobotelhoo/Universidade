Choosing a loop

Do you know how many times?

for · yes, I know

“for each item”, “10 times”, “every character”.

while · no idea

“until the user quits”, “until it reaches 1”.

Collatz from 7 — how many steps? nobody knows in advance

even → n // 2  ·  odd → 3 * n + 1

while · in action

Keep asking until the number is negative.

We can't know how many numbers the user will type. Try it — press Enter after each one.

number = int(input("Number: "))

while number >= 0:
    print("You typed", number)
    number = int(input("Number: "))
    
print("Negative number. Bye!")
